# JSON 格式化

一个纯前端、离线可用的 JSON 格式化页面。无需安装依赖，直接双击 `index.html` 即可使用，所有数据只在浏览器本地处理，不会上传到任何服务器。

## 功能

- **格式化**：支持 2 空格、4 空格、Tab 三种缩进
- **压缩**：移除所有可省略的空白，显示压缩前后体积
- **语法校验**：精确到行、列的报错，并在输入框行号处标记错误行
- **树形视图**：可折叠 / 展开节点，显示对象键数与数组长度
- **双侧查找替换**：输入区和结果区各有一套查找/替换栏，共享查询词；两侧命中同时高亮，支持上一个 / 下一个、区分大小写、正则表达式、单次替换与全部替换
- **双向联动**：点击左侧或右侧的命中项会滚动到另一侧对应内容；任意一侧替换都会回写左侧原始 JSON，并立即重新格式化右侧结果
- **层级配色**：右侧格式化结果按嵌套层级着色，键名、括号、值、行号和缩进参考线使用不同层级的颜色，值仍保留类型色
- **括号聚焦**：点击 `{}` / `[]` 或附近，成对高亮左右两个括号，并把该范围内的所有层级内容加粗、染成括号所在层级的颜色
- **撤销**：工具栏「撤销」或 `Ctrl/⌘ + Z` 可回退上一次文本修改，并立即同步右侧结果
- **键名排序**：格式化、压缩、树形视图保持一致
- **转义 / 去转义**：在 JSON 字符串与普通文本之间转换
- **导入 / 导出**：支持选择或拖放 `.json` 文件，把结果下载为 `.json`
- **复制**：一键复制当前结果（含剪贴板降级方案）
- **明暗主题**：跟随系统偏好，可手动切换并记住选择
- **自动保存**：输入草稿、缩进、排序、主题等偏好保存在 `localStorage`
- **快捷键**：`Ctrl/⌘ + Enter` 格式化，`Ctrl/⌘ + Shift + M` 压缩，`Ctrl/⌘ + F` 双侧查找，`Ctrl/⌘ + H` 直接聚焦替换框
- **响应式**：桌面端左右分栏可拖动调整，窄屏自动上下排列

## 双侧查找替换

左右两侧面板右上角都有「查找」按钮，打开后两侧共享同一个查询词和替换词：

- 在任意一侧输入查询，另一侧的输入框会同步，两个面板同时高亮全部命中
- `Enter` 下一个匹配，`Shift + Enter` 上一个匹配，`F3` 也可切换匹配
- 勾选 `Aa` 区分大小写，勾选 `.*` 使用 JavaScript 正则表达式
- 点击左侧命中所在行会自动滚动右侧到对应内容；点击右侧命中所在行会选中并滚动左侧对应内容
- 手机/窄屏下，点击联动后会自动把另一侧面板滚动到视野内
- 两侧的「替换 / 全部替换」都会修改左侧原始 JSON，并立即重新格式化右侧；修改后两侧计数与高亮同步刷新，右侧面板会有一次同步高亮反馈
- 查找栏打开期间，编辑输入并短暂停顿会自动同步右侧结果；打开查找栏时若结果已过期也会先自动同步
- 正则模式下替换内容支持 `$1`、`$2`、`$<name>`、`$&` 等捕获组引用
- 普通模式下替换内容按字面量处理，`$&` 不会被展开
- 点击「全部替换」前会确认替换数量，避免误操作
- 替换会直接修改左侧输入内容，且不进入浏览器原生撤销栈，建议确认后再操作
- `Esc` 关闭当前查找栏并清除高亮

只有当命中内容能在原始 JSON 中找到对应位置时，右侧才会执行替换；如果命中只存在于格式化空白中（例如 `": "` 这种由格式化产生的空格），右侧替换按钮会提示改在左侧操作。

## 括号聚焦

右侧格式化结果中的每个括号都带有层级信息：

- 点击 `{`、`[`、`}`、`]` 或括号附近（约 4 个字符内），会同时高亮这一对括号，包括位于另一行的闭合括号
- 该括号范围内所有层级的内容（键、值、标点、嵌套括号）都会加粗，并显示括号所在层级的颜色
- 再点同一对括号、点击其他内容或按 `Esc` 可取消聚焦
- 点击右侧其他嵌套括号会切换到那一层的范围
- 在左侧输入框点击括号，也会在右侧定位并聚焦对应的括号范围
- 顶部提示会显示这一对括号跨越的行号，例如「已聚焦 `{ … }` · 第 1–10 行」

## 撤销

- 工具栏「撤销」或 `Ctrl/⌘ + Z`，回退上一次**文本修改**
- 覆盖直接输入、粘贴/Tab 插入、替换、全部替换、清空、导入文件和载入示例
- 撤销后会立即重新格式化右侧并刷新查找高亮，两侧保持同步
- 默认最多保留 60 个历史快照，总字符数上限约 800 万；不提供重做
- 在查找/替换输入框内，`Ctrl/⌘ + Z` 仍用于回退输入框自身的编辑

## 打开方式

直接双击打开：

```text
index.html
```

也可以在当前目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 实现说明

- 解析器为自研实现，格式化时直接复用原始字面量，因此 **大整数不会丢精度**，`1.0`、`1e+10` 等写法也不会被改写。
- 严格遵循 JSON 语法：拒绝尾随逗号、单引号、注释、未转义控制字符、`NaN`、前导零等，并给出中文错误提示。
- 最大嵌套深度为 1000 层；树形视图最多渲染 8000 个节点，超出时提示切换回文本视图。
- 双侧查找栏每侧最多标记 3000 处匹配，超出时仍可替换但导航只在已标记范围内。
- 格式化结果在 1.5 MB 以内使用完整语法 + 层级配色；超过后自动切换为「层级纯色模式」，仍按行区分层级，但不再逐 token 上色。搜索高亮在 1.5 MB 以内可用，超过后保留计数与跳转但省略高亮。
- 右侧层级色板共 8 色循环，深层嵌套会复用颜色；行号、行号色条和缩进参考线同样按层级着色。
- 窄屏下两个面板使用固定高度并在内部滚动，不会因为超长 JSON 把页面撑成数万像素。
- 括号聚焦和完整语法配色需要丰富模式；超过 1.5 MB 的文本会切换为层级纯色模式，此时括号聚焦不可用。
- 不依赖任何第三方库、字体或 CDN，断网也能完整使用。
- 已在 Chrome / Edge 的桌面与 390px 窄屏尺寸下验证布局、双侧查找替换、点击联动、层级配色、长文本滚动与主要交互。
