# 开发工具箱

一个**纯前端、离线可用**的开发者工具集：JSON 格式化、Base64/URL 编码、哈希/MD5、AES 加解密、SQL 美化、时间戳转换、JWT 解析、UUID 生成、正则测试、进制与文本转换。

无第三方依赖、无构建步骤、无网络请求；双击 `index.html` 即可使用，所有数据只在浏览器本地处理。

## 工具一览

| 工具 | 路由 | 能力 |
|---|---|---|
| JSON 格式化 | `#/json` | 格式化、压缩、语法校验、树形视图、双侧查找替换、层级折叠、括号聚焦、撤销 |
| SQL 格式化 | `#/sql` | 关键字大小写、缩进、换行、压缩单行、注释移除，字符串与注释语义不变 |
| JWT 解析 | `#/jwt` | 解码 Header/Payload，展示 `exp` / `iat` / `nbf` 与过期状态（不验签） |
| Base64 / URL | `#/encode` | UTF-8 安全的 Base64、URL-safe 变体、URL 百分号编码与表单编码 |
| 哈希 / MD5 | `#/hash` | MD5、SHA-1/256/384/512、HMAC，输出 Hex 与 Base64 |
| AES 加解密 | `#/crypto` | AES-128/192/256，CBC / CTR / GCM，密钥与 IV 支持 UTF-8 / Hex / Base64 |
| 时间戳 | `#/timestamp` | 秒/毫秒/微秒时间戳互转、时区换算、相对时间、严格日期校验 |
| UUID / 随机串 | `#/uuid` | UUID v4、NanoID 风格随机串、随机密码，批量生成 |
| 正则测试 | `#/regex` | 实时高亮全部匹配，列出捕获组与命名组 |
| 进制与文本 | `#/text` | 任意进制大整数互转（BigInt）、命名风格、大小写与行级整理 |

左侧导航切换，URL 会同步为 `#/工具 id`，可直接收藏或分享；刷新后停留在上次使用的工具，浏览器前进/后退可切换。

## 打开方式

直接双击：

```text
index.html
```

或启动任意静态服务器（推荐，部分浏览器对 `file://` 的加密接口限制更严）：

```powershell
python -m http.server 8080
# 或
node -e "require('http').createServer((q,s)=>require('fs').createReadStream('.'+q.url.split('?')[0]||'/index.html').on('error',()=>{s.statusCode=404;s.end()}).pipe(s)).listen(8080)"
```

然后访问 `http://localhost:8080/`。

> AES 与 SHA/HMAC 依赖浏览器 WebCrypto（`crypto.subtle`）。现代浏览器把 `file://` 也视为安全上下文，通常可直接使用；若某个浏览器拒绝，工具会显示明确提示，改用 `http://localhost` 打开即可。MD5、Base64、SQL、时间戳等功能不依赖 WebCrypto。

## 快捷键

各工具的主操作统一为 `Ctrl/⌘ + Enter`，具体动作随工具变化（转换、重新计算、加密、格式化、用当前时间、重新生成等），页脚会显示当前工具的快捷键。

JSON 页额外支持：

- `Ctrl/⌘ + Enter` 格式化
- `Ctrl/⌘ + Shift + M` 压缩
- `Ctrl/⌘ + Z` 撤销
- `Ctrl/⌘ + F` 双侧查找，`Ctrl/⌘ + H` 聚焦替换
- `Enter` / `Shift + Enter` / `F3` 在匹配间跳转，`Esc` 关闭查找
- 方向键 / `Home` 在分隔条聚焦时调整左右宽度

所有快捷键只在对应工具激活时生效，不会劫持浏览器默认行为。

## 各工具说明

### JSON 格式化

- **格式化 / 压缩**：2 空格、4 空格、Tab 三种缩进；压缩后显示体积变化
- **语法校验**：精确到行、列的中文报错，并在行号栏标记错误行
- **树形视图**：可折叠节点，显示对象键数与数组长度
- **双侧查找替换**：输入区与结果区共享查询词，两侧同时高亮；支持区分大小写、正则、单次/全部替换
- **层级折叠**：行号栏 `+ / −` 折叠任意跨行对象或数组，折叠摘要形如 `… 5 个键 }`
- **括号聚焦**：点击 `{}` / `[]` 高亮成对括号并强调该层内容
- **大文件保护**：超 4000 行改用按行着色，超 5000 行不提供折叠，超 8000 行分段渲染
- **转义 / 去转义**、**导入 / 导出**、**撤销**、**键名排序**、**明暗主题**、**自动保存草稿**

解析器为自研实现，格式化时复用原始字面量，因此**大整数不会丢精度**，`1.0`、`1e+10` 等写法也不会被改写。

### SQL 格式化

自研 tokenizer，能正确区分：

- 字符串 `'...'`（含 `''` 与 `\'` 转义）、前缀字符串 `E'...'` / `N'...'` / `X'...'`
- 引号标识符 `"..."`、`` `...` ``、`[...]`
- 行注释 `--`、`#`（MySQL）与块注释 `/* ... */`
- 参数占位符 `?`、`:name`、`$1`、`@var`，以及 PostgreSQL 美元引用 `$$...$$`
- 数字（含 `0x` 十六进制与科学计数）、多字符运算符、`::` 类型转换

格式化规则：顶层子句（SELECT / FROM / WHERE / GROUP BY / ORDER BY / JOIN / UNION 等）各占一行，逗号断行，`AND` / `OR` / `CASE` / `WHEN` 缩进；函数参数保持单行，子查询另起一行缩进。

**语义安全**：格式化与压缩只改变空白与关键字大小写，不改变 token 序列（`tests.html` 用 token 签名校验）。压缩时行注释必须删除或保留换行，否则会把后续 SQL 注释掉，因此默认移除注释并提示数量。

### 哈希 / MD5

- MD5 为纯 JS 实现（WebCrypto 不提供 MD5），支持 UTF-8 与超长输入
- SHA-1/256/384/512 与 HMAC 使用浏览器内置实现
- 同时输出 Hex 与 Base64，可切换大小写，支持逐条或全部复制
- 空输入也会给出空串的摘要（这是正确结果，不是错误）

> MD5 与 SHA-1 已被证明存在碰撞，只能用于校验完整性，不要用于密码存储或签名。

### AES 加解密

| 模式 | 填充 | IV / Nonce | 说明 |
|---|---|---|---|
| CBC | PKCS#7（由 WebCrypto 自动完成） | 16 字节 | 与 Java / OpenSSL 的 `PKCS5Padding` 互通 |
| CTR | 无 | 16 字节计数器 | 流式，密文与明文等长 |
| GCM | 无（自带 16 字节 tag） | 12 字节 | 带认证，解密失败即说明密钥、IV 或数据有问题 |

- 密钥支持 UTF-8 / Hex / Base64，长度必须为 16 / 24 / 32 字节（AES-128/192/256）
- 密文输出支持 Base64 / Hex；勾选「IV 前置到密文」会把 IV 拼在密文前，解密时自动切分
- 解密结果若不是有效 UTF-8，会按十六进制展示并提示
- 密钥、IV、明文不写入 `localStorage`，刷新即清空

### 时间戳

- 当前时间实时刷新（可暂停），展示秒级、毫秒级、本地时间与 UTC
- 时间戳 → 时间：按位数自动识别 10 位=秒、13 位=毫秒、16 位=微秒，也可手动指定
- 时间 → 时间戳：输 `2026-11-19 22:03:34`、`2026/11/19`、`2026-11-19T14:03:34Z` 等格式，可选择输入时区
- 输出本地时间、所选时区、ISO 8601、UTC、RFC 2822、相对时间与星期
- 严格校验：不存在的日期（如 `2026-02-29`）、`24:00`、夏令时空档都会报错，不会静默进位
- 支持 1970 年之前的负时间戳；时区换算基于 `Intl.DateTimeFormat`，无需时区数据库

### JWT 解析

- 自动去掉 `Bearer ` 前缀，解码 Header 与 Payload 并格式化展示
- 展示 `alg` / `typ` / `kid`，把 `exp` / `iat` / `nbf` 转成本地时间并标注是否过期、是否生效
- 签名段只显示字节数，并明确提示**未验签**

> 该工具只做解码展示。要确认 token 可信，必须在服务端用密钥或公钥校验签名。

### UUID / 随机串

- UUID v4：批量 1–100 条，可选大写、去掉连字符
- NanoID 风格：自定义字符集与长度，使用拒绝采样避免取模偏差
- 随机密码：可选小写、大写、数字、符号，保证每类至少出现一个后打乱
- 随机源为 `crypto.getRandomValues`；不可用时直接报错，不会退回可预测的 `Math.random`

### 正则测试

- 修饰符 `i`（忽略大小写）、`m`（多行）、`s`（dotAll）、`u`（Unicode）、`y`（粘性）
- 始终列举全部匹配（内部按全局查找），高亮显示并列出位置、匹配文本、数字捕获组与命名组
- 零宽匹配会手动推进 `lastIndex`，不会死循环；文本上限 200K 字符，列表最多显示 200 条、最多记录 1000 条匹配

> JavaScript 正则无法中断执行，复杂的嵌套量词（如 `(a*)*`）仍可能让页面卡住，这是语言限制，请避免对超长文本使用高回溯风险的正则。

### 进制与文本

- **进制转换**：输入支持负号与 `0x` / `0b` / `0o` 前缀，输出 2/8/10/16/36 进制；使用 `BigInt` 解析，64 位以上整数不丢精度
- **文本格式化**：
  - 命名：`camelCase`、`PascalCase`、`snake_case`、`kebab-case`、`CONSTANT_CASE`
  - 大小写：全大写、全小写、标题格式
  - 行处理：去首尾空白、去空行、去重行、行排序、反转行
  - 统计：字符、字节、行、词；中文等 CJK 字符原样保留

## 自检

打开 `tests.html` 可以跑完整自检，覆盖：

- Base64 / Hex / Base64URL / PKCS#7 往返与非法输入
- MD5 RFC 1321 全向量、SHA-1/256/384/512 与 HMAC（RFC 4231）标准向量
- AES-CBC（NIST SP 800-38A）、AES-CTR（NIST F.5.1）、AES-GCM（NIST 用例，含 tag 校验）
- SQL 格式化的 token 序列不变性与幂等性、注释安全性
- 日期解析、时区换算、时间戳单位识别、BigInt 进制、命名转换、JWT 解码

页面顶部显示「通过 X 项 · 失败 Y 项」，失败项会列出期望值与实际值；`<title>` 也会变成 `PASS/FAIL`，便于自动化检查。全部用例都是标准测试向量，或与浏览器原生实现交叉验证。

## 实现说明

- **零依赖**：不引用任何第三方库、字体或 CDN，断网可用
- **无构建**：全部为普通 `<script>`，`js/lib/*` 采用 UMD 包装，既能在浏览器挂到全局，也能被 Node `require` 用于测试
- **路由与懒挂载**：`toolbox.js` 提供注册表与 hash 路由，每个工具的 `mount()` 只在首次进入时执行一次，切换工具只切换 `hidden`，输入内容与滚动位置都会保留
- **统一主操作**：工具声明 `run()` 后自动获得 `Ctrl/⌘ + Enter`
- **状态隔离**：每个工具在 `mount()` 内创建私有状态，工具之间不共享 DOM 或变量
- **错误隔离**：某个工具挂载失败会降级为该工具的提示，不影响其它工具与 JSON 页
- **缓存参数**：静态资源统一使用 `?v=8`，改动后递增即可绕过缓存

新增一个工具的步骤：在 `js/tools/` 下新建脚本，调用 `Toolbox.register({ id, group, title, desc, icon, mount, run })`，在 `index.html` 里按顺序引入；样式优先复用 `shell.css` 中的 `t-*` 组件与 `style.css` 中的 `.btn` / `.mini` / `.tab`。

## 隐私与安全

- 所有计算都在浏览器本地完成，工具不会发起任何网络请求
- 加密密钥、IV、明文、JWT 原文、SQL 与 JSON 内容都不会写入 `localStorage`；只有主题、分栏比例、JSON 草稿和工具选项会保存
- MD5 / SHA-1 仅用于校验，不适合密码或签名
- CBC 不提供完整性校验，需要防篡改时请选 GCM
- JWT 工具不验签，不要用它判断 token 是否可信
- 剪贴板「粘贴」按钮需要浏览器授权，仅在用户点击时读取

## 已知限制

- 不做 RSA / EC 非对称加解密，不做 AES-ECB、DES/3DES、RC4（WebCrypto 不支持，需额外自研实现）
- GCM 暂不支持 AAD
- JWT 只解码，不验签、不校验 `aud` / `iss`
- SQL 工具不绑定具体方言，也不做语义校验；`#` 仅在行首或后跟空白时视为注释（避免与 PostgreSQL 的 `#` 运算符冲突）
- 正则测试无法中断超长回溯，请控制文本长度与正则复杂度
- WebCrypto 相关功能依赖安全上下文（`https`、`localhost`，现代浏览器也包含 `file://`）

## 浏览器支持

在 Chrome / Edge 桌面与 390px 窄屏下验证，使用 ES2015+ 与 WebCrypto；不支持 IE。核心工具（JSON、Base64、SQL、时间戳、进制）在较旧浏览器中也可工作，加密与摘要功能需要 WebCrypto。
