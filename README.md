# 开发工具箱

一个**纯前端、离线可用**的开发者工具集：JSON 格式化、Base64/URL 编码、哈希/MD5、AES 加解密、**16 种数据库方言的 SQL 美化与语法检查**、时间戳转换、JWT 解析、UUID 生成、正则测试、进制与文本转换，以及一个带行号、语法着色、**撤销重做与查找高亮**的多文档便签。

无第三方依赖、无构建步骤、无网络请求；双击 `index.html` 即可使用，所有数据只在浏览器本地处理。

左侧导航切换，URL 会同步为 `#/工具 id`，可直接收藏或分享；刷新后停留在上次使用的工具，浏览器前进/后退可切换。

**每个页签都支持搜索与高亮**：右上角的「查找」按钮或 `Ctrl/⌘ + F` 会在当前页签打开查找条（`Ctrl/⌘ + H` 直接聚焦替换框），`Enter` / `Shift + Enter` 在命中之间跳转，`Esc` 关闭。**文本域里的命中会真的被涂上颜色**（深浅两色区分「全部命中」与「当前命中」），而不是只靠选区。JSON 页签使用它自己的双侧查找。

**每个页签都支持撤销 / 重做**：顶栏右侧有统一的按钮，键盘上是 `Ctrl/⌘ + Z` 撤销、`Ctrl + Y`（或 `Ctrl/⌘ + Shift + Z`）重做。连续输入会按时间合并成一步，撤销后光标与滚动位置一起还原。

所有页签的选项统一为**左侧标签、右侧控件**（与 JSON 工具栏一致），模式类选项做成并排的分段按钮而不是下拉框。

## 打开方式

直接双击：

```text
index.html
```

或启动任意静态服务器（推荐，部分浏览器对 `file://` 的加密接口限制更严）：

```powershell
python -m http.server 8080
# 或
node -e "require('http').createServer((q,s)=>require('fs').createReadStream('.'+q.url.split('?')[0]||'/index.html').on('error',()=>{s.statusCode=404;s.end()}).pipe(s)).listen(8080)"
```

然后访问 `http://localhost:8080/`。

> AES 与 SHA/HMAC 依赖浏览器 WebCrypto（`crypto.subtle`）。现代浏览器把 `file://` 也视为安全上下文，通常可直接使用；若某个浏览器拒绝，工具会显示明确提示，改用 `http://localhost` 打开即可。MD5、Base64、SQL、时间戳等功能不依赖 WebCrypto。

## 快捷键

各工具的主操作统一为 `Ctrl/⌘ + Enter`，具体动作随工具变化（转换、重新计算、加密、格式化、用当前时间、重新生成等），页脚会显示当前工具的快捷键。

所有页签通用：

- `Ctrl/⌘ + Z` 撤销，`Ctrl + Y` / `Ctrl/⌘ + Shift + Z` 重做
- `Ctrl/⌘ + F` 查找，`Ctrl/⌘ + H` 查找并聚焦替换框
- `Enter` / `Shift + Enter` 在命中间跳转，`Esc` 关闭查找条

JSON 页额外支持：

- `Ctrl/⌘ + Enter` 格式化
- `Ctrl/⌘ + Shift + M` 压缩
- `Ctrl/⌘ + Z` 撤销
- `Ctrl/⌘ + F` 双侧查找，`Ctrl/⌘ + H` 聚焦替换
- `Enter` / `Shift + Enter` / `F3` 在匹配间跳转，`Esc` 关闭查找
- 方向键 / `Home` 在分隔条聚焦时调整左右宽度

所有快捷键只在对应工具激活时生效，不会劫持浏览器默认行为。

## 各工具说明

### JSON 格式化

- **格式化 / 压缩**：2 空格、4 空格、Tab 三种缩进；压缩后显示体积变化
- **语法校验**：精确到行、列的中文报错，并在行号栏标记错误行
- **树形视图**：可折叠节点，显示对象键数与数组长度
- **双侧查找替换**：输入区与结果区共享查询词，两侧同时高亮；支持区分大小写、正则、单次/全部替换
- **层级折叠**：行号栏 `+ / −` 折叠任意跨行对象或数组，折叠摘要形如 `… 5 个键 }`
- **括号聚焦**：点击 `{}` / `[]` 高亮成对括号并强调该层内容
- **大文件保护**：超 4000 行改用按行着色，超 5000 行不提供折叠，超 8000 行分段渲染
- **转义 / 去转义**、**导入 / 导出**、**撤销**、**键名排序**、**明暗主题**、**自动保存草稿**

解析器为自研实现，格式化时复用原始字面量，因此**大整数不会丢精度**，`1.0`、`1e+10` 等写法也不会被改写。

### SQL 格式化 / 语法检查

**支持 16 种数据库方言**，语法着色、关键字大小写、语法检查、关键字提示都按所选方言进行：

| 分组 | 方言 |
|---|---|
| 标准 | 标准 SQL（ANSI） |
| 开源系 | MySQL · MariaDB · TiDB · OceanBase · PostgreSQL · SQLite · ClickHouse |
| 国产系 | **金仓 KingbaseES** · **达梦 DM8** · openGauss / GaussDB |
| 商业系 | Oracle · SQL Server · IBM Db2 |
| 大数据系 | Apache Hive · Spark SQL |

- 方言下拉按分组展示，每个方言带版本提示；勾选「自动识别方言」时会根据 SQL 特征（反引号、`::`、`ROWNUM`、`TOP n`、`PREWHERE`、`WITH UR`、`PRAGMA` 等）自动切换
- 选择会记在 `localStorage`，下次打开仍是上次的方言

自研 tokenizer 会按方言裁剪规则，能正确区分：

- 字符串 `'...'`（含 `''` 与 `\'` 转义）、前缀字符串 `E'...'` / `N'...'` / `X'...'` / `Q'...'`
- 引号标识符 `"..."`、`` `...` ``（MySQL 系）、`[...]`（SQL Server）—— 只在支持的方言里才当标识符，PostgreSQL 里的 `arr[1]` 仍然按数组下标处理
- 行注释 `--`、`#`（MySQL 系）与块注释 `/* ... */`
- 参数占位符 `?`、`:name`、`$1`、`@var`、`@@global`，以及 PostgreSQL 美元引用 `$$...$$`
- 数字（含 `0x` 十六进制与科学计数）、各方言特有的多字符运算符（`::`、`->>`、`#>>`、`@>`、`<=>`、`||`、`!~*` 等）

格式化规则：顶层子句（SELECT / FROM / WHERE / GROUP BY / ORDER BY / JOIN / UNION 等）各占一行，逗号断行，`AND` / `OR` / `CASE` / `WHEN` 缩进；函数参数保持单行，子查询另起一行缩进。

**输出为彩色语法高亮**：关键字、类型、函数、字符串、数字、注释、参数各有独立配色（明暗主题各一套），并带行号，长 SQL 可直接对着行号定位。

**语法检查**：底部面板实时列出问题，每条都带「错误 / 警告」标签、中文说明与 `行:列`，点一下就把光标与滚动定位到出错位置，同时在输入框里用波浪线标出对应片段。覆盖的检查包括：

- 未闭合的字符串、注释、引号标识符、方括号标识符
- 括号不配对（多了 / 少了）、`CASE` 与 `END` 不配对
- 尾逗号（`, FROM`、`, )`、语句以逗号结尾）
- 子句顺序颠倒（`WHERE` 写到 `GROUP BY` 后面等）
- `JOIN` 缺 `ON` / `USING`、`ON` 前面没有 `JOIN`
- `INSERT` 缺 `VALUES` / `SELECT`、`FROM` 后缺表名、`WHERE` 等关键字后面缺内容
- `UPDATE` / `DELETE` 没有 `WHERE`（全表操作提醒）
- 把关键字当列名使用、类型长度参数不合理、`SELECT *`
- **方言差异提示**：例如在 MySQL 里写 `SELECT TOP 10`、在 Oracle 里写 `LIMIT`、在 MySQL 里写 `ROWNUM`，都会给出「这个库应该怎么写」的提示

检查器用启发式而非完整语法分析：它**从不抛异常**，任何畸形输入都会被降级成一条诊断继续检查；超过 200k 字符只检查前面部分。

**关键字提示补全**：输入时自动弹出候选（关键字 / 类型 / 函数按当前方言过滤），`↑` `↓` 选择、`Enter` 或 `Tab` 补全、`Esc` 关闭，`Ctrl + Space` 可以手动唤出。

**语义安全**：格式化与压缩只改变空白与关键字大小写，不改变 token 序列（`tests.html` 用 token 签名校验，8 个方言各跑一遍）。压缩时行注释必须删除或保留换行，否则会把后续 SQL 注释掉，因此默认移除注释并提示数量。

### 哈希 / MD5

- MD5 为纯 JS 实现（WebCrypto 不提供 MD5），支持 UTF-8 与超长输入
- SHA-1/256/384/512 与 HMAC 使用浏览器内置实现
- 同时输出 Hex 与 Base64，可切换大小写，支持逐条或全部复制
- 空输入也会给出空串的摘要（这是正确结果，不是错误）

> MD5 与 SHA-1 已被证明存在碰撞，只能用于校验完整性，不要用于密码存储或签名。

### AES 加解密

| 模式 | 填充 | IV / Nonce | 说明 |
|---|---|---|---|
| CBC | PKCS#7（由 WebCrypto 自动完成） | 16 字节 | 与 Java / OpenSSL 的 `PKCS5Padding` 互通 |
| CTR | 无 | 16 字节计数器 | 流式，密文与明文等长 |
| GCM | 无（自带 16 字节 tag） | 12 字节 | 带认证，解密失败即说明密钥、IV 或数据有问题 |

- 密钥支持 UTF-8 / Hex / Base64，长度必须为 16 / 24 / 32 字节（AES-128/192/256）
- 密文输出支持 Base64 / Hex；勾选「IV 前置到密文」会把 IV 拼在密文前，解密时自动切分
- 解密结果若不是有效 UTF-8，会按十六进制展示并提示
- 密钥、IV、明文不写入 `localStorage`，刷新即清空

### 时间戳

- 当前时间实时刷新（可暂停），以紧凑网格展示秒级、毫秒级、本地时间与 UTC
- 时间戳 → 时间：按位数自动识别 10 位=秒、13 位=毫秒、16 位=微秒，也可手动指定
- 时间 → 时间戳：输 `2026-11-19 22:03:34`、`2026/11/19`、`2026-11-19T14:03:34Z` 等格式，可选择输入时区
- 输出**秒级、毫秒级**、本地时间（含星期与时区偏移）、ISO 8601、UTC、RFC 2822、相对时间
- 严格校验：不存在的日期（如 `2026-02-29`）、`24:00`、夏令时空档都会报错，不会静默进位
- 支持 1970 年之前的负时间戳；时区换算基于 `Intl.DateTimeFormat`，无需时区数据库
- 值区域采用「主值 + 副行」两行布局并按需换行，**长时区名与毫秒不会被截断**

### JWT 解析

- 自动去掉 `Bearer ` 前缀，解码 Header 与 Payload 并格式化展示
- 展示 `alg` / `typ` / `kid`，把 `exp` / `iat` / `nbf` 转成本地时间并标注是否过期、是否生效
- 签名段只显示字节数，并明确提示**未验签**

> 该工具只做解码展示。要确认 token 可信，必须在服务端用密钥或公钥校验签名。

### UUID / 随机串

- UUID v4：批量 1–100 条，可选大写、去掉连字符
- NanoID 风格：自定义字符集与长度，使用拒绝采样避免取模偏差
- 随机密码：可选小写、大写、数字、符号，保证每类至少出现一个后打乱
- 随机源为 `crypto.getRandomValues`；不可用时直接报错，不会退回可预测的 `Math.random`

### 正则测试

- 修饰符 `i`（忽略大小写）、`m`（多行）、`s`（dotAll）、`u`（Unicode）、`y`（粘性）、`g`（全局），一键开关
- 支持 `/pattern/flags` 斜杠写法，会自动拆出正则与修饰符
- 始终列举全部匹配（内部按全局查找），高亮显示并列出位置、匹配文本、数字捕获组与命名组
- 正则非法时给中文提示，且不会清空已输入内容
- 替换：支持 `$1` `$&`` $` `` `$'` `$$` 与 `$<name>`，可单次或全部替换
- 拆分：按当前正则拆分文本并列出结果
- 示例库与语法速查表，可一键填充；当前正则可导出为 JavaScript / Java / Python 代码
- 零宽匹配会手动推进 `lastIndex`，不会死循环；文本上限 200K 字符，列表最多显示 200 条、最多记录 1000 条匹配

> JavaScript 正则无法中断执行，复杂的嵌套量词（如 `(a*)*`）仍可能让页面卡住，这是语言限制，请避免对超长文本使用高回溯风险的正则。

### 进制与文本

- **进制转换**：输入支持负号与 `0x` / `0b` / `0o` 前缀，输出 2/8/10/16/36 进制；使用 `BigInt` 解析，64 位以上整数不丢精度
- **文本格式化**：
  - 命名：`camelCase`、`PascalCase`、`snake_case`、`kebab-case`、`CONSTANT_CASE`
  - 大小写：全大写、全小写、标题格式
  - 行处理：去首尾空白、去空行、去重行、行排序、反转行
  - 统计：字符、字节、行、词；中文等 CJK 字符原样保留

### 便签

**文档管理**

- 多文档标签页：新建、重命名、复制、删除、切换，最多 30 个
- 侧栏列表可按**更新时间 / 名称 / 长度**排序，选择会被记住
- **锁定便签**：锁定后编辑器只读，标签与列表都会显示锁标记，避免误改；锁定状态写入本机
- 自动保存到 `localStorage`（约 600ms 防抖），`Ctrl/⌘ + S` 立即保存，刷新或关页面都不丢；顶栏有「已保存 / 未保存」状态点

**编辑**

- **行号 + 语法着色**：JavaScript / SQL / JSON / Java / Python / XML / CSS / Markdown / Shell / Properties 共 10 种语言，可随时切换
- **撤销 / 重做**：`Ctrl/⌘ + Z` 与 `Ctrl + Y`（或 `Ctrl/⌘ + Shift + Z`），工具栏与顶栏都有按钮；切换便签时历史栈独立，不会把别的便签内容撤回来
- 当前行在行号栏高亮；`Tab` 缩进两个空格，`Shift + Tab` 反缩进，选中多行时整块缩进
- **点击行号选中整行**
- **行操作**：上移行、下移行、复制行、删除行、注释 / 取消注释（按语言自动选 `//`、`--`、`#` 或 `<!-- -->`），支持多行选区；快捷键 `Alt + ↑/↓`、`Ctrl + D`、`Ctrl + /`、`Ctrl + Shift + K`
- 可切换自动换行与行号显示

**查找与检索**

- **查找高亮**：`Ctrl/⌘ + F` 查找、`Ctrl/⌘ + H` 替换，命中在编辑器里真实着色，当前命中单独强调；`Enter` / `Shift + Enter` 跳转时编辑器会跟着滚动
- **跨便签搜索**：侧栏搜索框一次搜全部便签的名称与内容，结果按「便签名 · 第 N 行」列出带上下文的片段，点一下即跳到对应便签、选中该处并同步打开查找条；结果超过 80 条会提示剩余数量
- 全部替换会先确认，完成后提示替换数量

**导入导出**

- 导入本地文本文件为新便签（自动猜语言）
- 导出当前便签，扩展名按语言决定（`.md` / `.sql` / `.json` / `.txt`）
- **全部导出**为一个 JSON 备份文件，可再**全部导入**合并回来（按 id 与名称去重，冲突时生成「副本」）

**统计**

- 实时统计字符、词、行、字节、选中字符数，并估算阅读时间（约 400 字 / 分钟）
- 内容只存在本机浏览器，不上传

## 自检

打开 `tests.html` 可以跑完整自检，覆盖：

- Base64 / Hex / Base64URL / PKCS#7 往返与非法输入
- MD5 RFC 1321 全向量、SHA-1/256/384/512 与 HMAC（RFC 4231）标准向量
- AES-CBC（NIST SP 800-38A）、AES-CTR（NIST F.5.1）、AES-GCM（NIST 用例，含 tag 校验）
- SQL 格式化的 token 序列不变性与幂等性、注释安全性，**8 种方言各跑一遍**
- SQL 方言表完整性、别名解析、方言自动识别
- SQL 语法检查：未闭合字符串 / 注释 / 括号、尾逗号、子句顺序、`JOIN` 缺 `ON`、`INSERT` 缺 `VALUES`、无 `WHERE` 的全表操作、方言差异提示、诊断排序与偏移范围
- 日期解析、时区换算、时间戳单位识别、BigInt 进制、命名转换、JWT 解码
- 语法着色：HTML 转义安全、还原原文、10 种语言的方言识别

## 实现说明

- **零依赖**：不引用任何第三方库、字体或 CDN，断网可用
- **无构建**：全部为普通 `<script>`，`js/lib/*` 采用 UMD 包装，既能在浏览器挂到全局，也能被 Node `require` 用于测试
- **路由与懒挂载**：`toolbox.js` 提供注册表与 hash 路由，每个工具的 `mount()` 只在首次进入时执行一次，切换工具只切换 `hidden`，输入内容与滚动位置都会保留
- **统一主操作**：工具声明 `run()` 后自动获得 `Ctrl/⌘ + Enter`
- **统一查找**：工具声明 `find(options)` 后自动获得 `Ctrl/⌘ + F` 与右上角「查找」按钮；未声明的工具由外壳兜底挂到视图里第一个可编辑文本域。文本域的高亮由 `text-mirror.js` 叠一层排版一致的透明文本实现，不干扰输入、选区与滚动
- **统一撤销**：`history.js` 给每个文本域一份独立历史栈并接管 `Ctrl+Z / Ctrl+Y`；工具只要 `Toolbox.setHistoryTarget(id, textarea)` 登记主文本域，顶栏与工具内按钮就都作用于它
- **状态隔离**：每个工具在 `mount()` 内创建私有状态，工具之间不共享 DOM 或变量
- **错误隔离**：某个工具挂载失败会降级为该工具的提示，不影响其它工具与 JSON 页
- **缓存参数**：静态资源统一使用 `?v=10`，改动后递增即可绕过缓存

新增一个工具的步骤：在 `js/tools/` 下新建脚本，调用 `Toolbox.register({ id, group, title, desc, icon, mount, run, find })`，在 `index.html` 里按顺序引入；样式优先复用 `shell.css` / `enhance.css` 中的 `t-*`、`seg`、`code-view` 组件与 `style.css` 中的 `.btn` / `.mini` / `.tab`。

需要行号或彩色输出时，用 `Toolbox.ui.codeView({ language, value })` 或 `codeEditor(...)`；需要查找替换时，用 `Finder.attach(host, { targets, label })` 并在工具的 `find` 里返回 `controller.show(replace)`。

## 隐私与安全

- 所有计算都在浏览器本地完成，工具不会发起任何网络请求
- 加密密钥、IV、明文、JWT 原文、SQL 与 JSON 内容都不会写入 `localStorage`；只有主题、分栏比例、JSON 草稿、工具选项与**便签内容**会保存
- 便签内容存在本机浏览器的 `localStorage` 里，明文可读；不要在便签里长期存放密码或密钥，公用电脑上用完请删除
- MD5 / SHA-1 仅用于校验，不适合密码或签名
- CBC 不提供完整性校验，需要防篡改时请选 GCM
- JWT 工具不验签，不要用它判断 token 是否可信
- 剪贴板「粘贴」按钮需要浏览器授权，仅在用户点击时读取

## 已知限制

- 不做 RSA / EC 非对称加解密，不做 AES-ECB、DES/3DES、RC4（WebCrypto 不支持，需额外自研实现）
- GCM 暂不支持 AAD
- JWT 只解码，不验签、不校验 `aud` / `iss`
- SQL 工具不绑定具体方言，也不做语义校验；`#` 仅在行首或后跟空白时视为注释（避免与 PostgreSQL 的 `#` 运算符冲突）
- 正则测试无法中断超长回溯，请控制文本长度与正则复杂度
- WebCrypto 相关功能依赖安全上下文（`https`、`localhost`，现代浏览器也包含 `file://`）

## 浏览器支持

在 Chrome / Edge 桌面与 390px 窄屏下验证，使用 ES2015+ 与 WebCrypto；不支持 IE。核心工具（JSON、Base64、SQL、时间戳、进制）在较旧浏览器中也可工作，加密与摘要功能需要 WebCrypto。
